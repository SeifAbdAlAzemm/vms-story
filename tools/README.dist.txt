VMS · A BUSINESS ANALYSIS STORY — interactive presentation
=========================================================

HOW TO OPEN
  Double-click index.html. It runs fully offline: no internet, no server, no install.
  Recommended browser: Google Chrome or Microsoft Edge (latest).

CONTROLS
  Right Arrow / Space / Page Down   next beat
  Left Arrow / Page Up              previous beat
  Home                              beginning
  End                               finale
  N                                 show / hide presenter notes (never shown in fullscreen)
  Mouse wheel / trackpad            free scroll for Q&A (does not break the beats)
  Journey rail dots (bottom)        jump to a chapter
  Presentation clickers that send Page Down / Page Up or arrow keys work out of the box.

FULLSCREEN
  Click "Present" (bottom-right) or press F11. Press Esc to leave fullscreen.

IF THE LAYOUT LOOKS WRONG
  Reset browser zoom with Ctrl + 0 (Cmd + 0 on Mac). The story scales itself to any screen.

PROTOTYPE SCREENS (team-created, illustrative data)
  Beat 33 shows the team's prototype: License Register (hero), Movement Dashboard
  and Maintenance Dashboard. Their records and counts are sample data — present them
  as illustrative, never as business figures.
  To replace a screen: overwrite src/assets/prototype/prototype_03.png (License Register),
  prototype_04.png (Movement Dashboard) or prototype_01.png (Maintenance Dashboard),
  then in the project folder run  npm install  (first time only)  and  npm run build.
  prototype_02.png (Trip Log) and prototype_05.png (Drivers) are kept in the source
  folder for Q&A; they are not part of the presentation.
